# 领域文档

本仓库采用单上下文布局，共享根目录的术语表和架构决策记录。

## 探索代码前

- 阅读根目录的 `GLOSSARY.md`。
- 阅读 `docs/adr/` 中与当前工作相关的架构决策记录。

文件或目录尚不存在时，直接继续工作。
在实际明确术语或决策时，由 `domain-modeling` 技能按需创建。

## 文件布局

- `GLOSSARY.md`：全仓库共享的领域术语表。
- `docs/adr/`：全仓库的架构决策记录。

## 使用领域术语

Issue 标题、设计建议、问题假设和测试名称涉及领域概念时，
使用术语表定义的名称，并遵循其中的用词约定。

所需概念尚未收录时，先判断它是否符合项目现有语言；
确有缺口时，记录为后续领域建模的输入。

## 架构决策冲突

方案与现有 ADR 冲突时，明确指出对应 ADR、
冲突内容及建议重新讨论的原因。
